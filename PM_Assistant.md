# PM Assistant

## Goal

Своё приложение для расшифровки рабочих звонков (превращение речи в текст): заходит в Zoom и Google Meet как бот, пишет системный звук во время Яндекс.Телемоста, расшифровывает на русском языке и достаёт список задач из разговора. Успех — приложение реально заменяет ручные заметки хотя бы на одном настоящем созвоне.

## Current Focus

**Prod:** v0.2.8 на EC2 `16.171.52.89`, коммит `a93cca5`, выкачено 2026-09-06. Google Календарь (OAuth-подключение, экран `/calendar`), поля ввода Client ID/Secret в Настройках, LLM-адаптеры, прогресс Whisper, очередь расшифровок, журнал воркера, статус `waiting_room`, мобильная адаптивная вёрстка (`.autopilot/2026-09-06-mobile-responsive/`). `doctor.sh` и `/api/health` зелёные.

**Локально, не выкачено:** месячная сетка календаря на `/calendar` — клик по дню фильтрует список, стрелки листают месяц. 311/311 тестов, `npm run build` ок.

Локально совпадает с продом. На столе: ручная настройка Google Cloud Console — без неё кнопка «Подключить» на проде отдаёт 503 (см. Next Actions).

## AI Brief

**Project:** PM Assistant
**Goal:** Своё приложение для расшифровки звонков (Zoom / Google Meet / Яндекс.Телемост) с упором на русский язык
**Stack / Domain:** Vite + React + TypeScript, Hono (Node), SQLite, локальный Node-воркер
**Current Focus:** Google Календарь и мобильная адаптивная вёрстка сданы (v0.2.6-0.2.8). Next: живой Zoom/Meet по ссылке пользователя, деплой календаря на EC2 отдельным пакетом.
**Key constraints:** только личное использование; бот заходит как участник во все три платформы (для Телемоста — без официального API); русский язык — приоритет качества распознавания; первая сдача без живого календаря и без живой отправки в Asana

## Open Questions

Все открытые вопросы закрыты, история решений — в Decisions Log.

Подтверждено исследованием: Телемост нативно расшифровывает звонки («Конспект от Алисы Про»), но только на платных корпоративных тарифах, без API, без реального времени, с удалением записи через 24 часа. Ни одна из 6 западных платформ (Otter/Fireflies/Fathom/Grain/tl;dv/MeetGeek) не поддерживает Телемост — но 3-4 российских сервиса (Speech2Text, mymeet.ai, Конспектор) уже туда подключаются гостевым ботом. Полный разбор — в [спецификации](artifacts/2026-09-03-pm-assistant-spec.md#6-открытые-вопросы-требующие-ответа-до-реализации).

Не вопрос к пользователю, решится тестом при реализации: движок распознавания (MacWhisper vs GigaAM-v3), диаризация в Телемосте через гостевого бота.
