# PM Assistant

## Goal

Своё приложение для расшифровки рабочих звонков (превращение речи в текст): заходит в Zoom и Google Meet как бот, пишет системный звук во время Яндекс.Телемоста, расшифровывает на русском языке и достаёт список задач из разговора. Успех — приложение реально заменяет ручные заметки хотя бы на одном настоящем созвоне.

## Current Focus

**Prod:** v0.2.1 на EC2 `16.171.52.89` (2026-09-05). Локально оболочка сверена с макетом `gGl1a` (сайдбар + без колокольчика). На прод это ещё не выкачено. Следующий продуктовый шаг: живой Zoom + `GOOGLE_CLIENT_*` / токены трекеров.

## AI Brief

**Project:** PM Assistant
**Goal:** Своё приложение для расшифровки звонков (Zoom / Google Meet / Яндекс.Телемост) с упором на русский язык
**Stack / Domain:** Vite + React + TypeScript, Hono (Node), SQLite, локальный Node-воркер
**Current Focus:** Локально Главная и сайдбар сверены с `02-home-transcript-v2.pen` (`MY7XW`, `gGl1a`). Prod 0.2.1 ещё со старым UI. Next: выкатка или живой Zoom.
**Key constraints:** только личное использование; бот заходит как участник во все три платформы (для Телемоста — без официального API); русский язык — приоритет качества распознавания; первая сдача без живого календаря и без живой отправки в Asana
