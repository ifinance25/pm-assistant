# 2026-09-05 — Диагноз качества расшифровки и отдельный репозиторий

## Executive summary

Разбирались, почему расшифровки звонков плохого качества. Замеры показали, что дело **не в движке распознавания, а в записи звука**: бот местами пишет полную тишину, а Whisper на тишине выдумывает текст и кладёт выдумку в базу как настоящую расшифровку. Там, где звук есть, он слишком тихий, и нормализации громкости в коде не было нигде.

Закрыли первые две фазы плана: тишину больше не расшифровываем, выдумки фильтруются детерминированно, громкость выравнивается перед Whisper. Выкатили на EC2. Код проекта переехал в собственный приватный репозиторий — раньше vault указывал на репозиторий чужого проекта и ни разу никуда не пушился.

## Диагноз: что измерено

| Факт | Значение |
|---|---|
| `73174160-...wav` | ровно **-91 dB** — цифровая тишина 36 секунд. В базе на нём «Продолжение следует...» x2, растянутое до 60 с |
| `9fb04c29` на проде | шесть одинаковых «Редактор субтитров Н.Закомолдина» ровно через каждые 30 секунд — окно Whisper |
| Живые записи | -38.0 / -25.1 / -20.6 dB средней громкости; самый тихий дал самую грубую ошибку («лаланки» вместо «колонки») |
| Нормализация громкости | отсутствовала и в `join.mjs`, и в `trim-silence.ts` |
| Модель на проде | `ggml-small.bin`, а эталоны в regression-папке делались на `large-v3-turbo` — прод хуже эталонов |
| Разделение по спикерам | невозможно: все голоса смешиваются в один моно-поток до записи |

Снятая гипотеза: флаг `-nt` **не** ломает таймкоды. В `whisper.cpp/examples/cli/cli.cpp` функция `output_json` пишет `offsets` безусловно — проверено по исходнику, а не по догадке.

## Решения и почему

1. **Причина плохого качества — захват, не движок.** Менять модель раньше починки записи бессмысленно: на тишине любой движок выдаст мусор. Это перевернуло порядок работ: сначала защита от выдумок и громкость, движок — в конце.

2. **Claude не заменит Whisper.** Пользователь предложил использовать оплаченную подписку Claude Code для распознавания. У модели нет входа для аудио — ни у API, ни у подписки. Подписка остаётся на вычитке готового текста (`revise.ts`).

3. **Таймкод идёт от первого слова.** Ожидание входа бота в звонок в таймкоде не нужно. Убрали `applyLeadingOffset`, который срезанную тишину прибавлял обратно.

4. **Обработанный файл заменяет исходную запись.** Иначе плеер и текст считали бы время от разных нулей. Оригинал удаляется, но только после проверки готового файла; перед выкаткой сделана копия на сервере.

5. **Фильтр выдумок детерминированный.** Заученные титры Whisper («Продолжение следует», «Редактор субтитров») вырезаются списком, без обращения к языковой модели: не тратит запросы и не ломается при лимите 429. LLM-вычитка остаётся вторым слоем.

6. **Отдельный репозиторий.** Vault указывал на `ArianaTent-MiniApp` — репозиторий другого проекта, на тестовой ветке третьего, и ни разу не пушился. Пуш отправил бы в облако 592 файла личной базы знаний. Выбрали приватный `ifinance25/pm-assistant` только под код проекта.

7. **Supadata — второй движок, не замена.** Аккаунт оплачен, распознаёт файлы по ссылке. Заблокирован: файл должен быть публично доступен, а приложение слушает только `127.0.0.1`. Разделения по спикерам в ответе Supadata нет.

## Результат

Громкость на трёх реальных записях:

| Файл | Было | Стало |
|---|---|---|
| `60b10313` | -38.0 dB | -26.7 dB |
| `88d2f102` | -25.1 dB, перегруз | -16.9 dB, перегруза нет |
| `db62a0b2` | -20.6 dB | -17.4 dB |

Текст на худшем файле стал с пунктуацией и разбился на 6 нормальных реплик вместо 3 слипшихся, уверенность модели выросла. **Ослышка осталась:** «лаланки» -> «элаланки», должно быть «колонки». Громкость эту ошибку не лечит — её закроет словарь терминов (фаза 5.2).

209 тестов проходят. Выкачено на EC2, `doctor: всё ок`.

## Открытые хвосты

- Старые плохие расшифровки в базе остались: фильтр работает только при новой расшифровке.
- У папки `Projects/PM Assistant/` теперь свой `.git` внутри vault, а vault продолжает отслеживать те же файлы. Два источника правды — разобрать отдельно.
- Почему хук захвата не поймал звук — ответит только живой звонок с замером RMS из фазы 3.
