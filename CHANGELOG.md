## [0.2.5] - 2026-09-06

_Выкладки: 2026-09-06 00:44 (`6ea70da`) → EC2 `16.171.52.89`_

### Добавлено

- Google Календарь: экран `/calendar`, события на 7 дней, кнопка «Отправить бота»; OAuth через общий Google client
- API календаря: `GET /api/calendar/events`, подключение и отключение интеграции
- Очередь расшифровок на Главной и `GET /api/transcription-queue`
- Журнал воркера: `GET /api/logs`
- LLM: вопрос по расшифровке (`ask`), провайдеры Claude / OpenAI / Cursor, OAuth и ключи в настройках
- Прогресс Whisper: текст и ETA по ходу расшифровки, таймаут 23 ч, снятие дублей `transcribe`

### Изменено

- Три очереди воркера: запись (`join`), расшифровка (`transcribe`) и саммари (`summarize`) независимы
- Экран встречи: абзацы одного спикера, фиксированная шапка и плеер, прокрутка текста в кадре
- Главная и архив: колонка «Следующие по ссылке», архив v2 по макету
- Восстановление зависших заданий при старте воркера

## [0.2.3] - 2026-09-05

_Выкладки: 2026-09-05 20:53 (`6ea70da`) → EC2 `16.171.52.89`_

### Изменено

- Три очереди воркера: запись в Zoom (`join`), расшифровка Whisper (`transcribe`) и саммари LLM (`summarize`) идут независимо
- После звонка бот сразу свободен для следующего созвона; Whisper и резюме не держат вход в встречу
- Выкладка пачкой: мелкие правки копятся в `unreleased`, `sync.sh` сначала проверяет, что воркер на проде свободен
- Экран встречи: фрагменты Whisper одного спикера склеиваются в абзацы (до 1000 символов по предложениям); шапка и плеер статичны, текстовая дорожка прокручивается в своём кадре без полосы; поиск и текущий таймкод поднимают блок на верх кадра

## [0.2.1] - 2026-09-05

_Выкладки: 2026-09-05 13:00 (`4e3054f`) → EC2 `16.171.52.89`; 2026-09-05 13:07 (`4e3054f`) → EC2 `16.171.52.89`; 2026-09-05 15:26 (`4e3054f`) → EC2 `16.171.52.89`_

### Добавлено

- Allowlist Google OAuth, проверка `email_verified` и cookie `state` (CSRF)
- Смена пароля через `POST /api/auth/password`
- `tsc --noEmit` в `npm test`, `npm run lint` (Biome)
- Баннер «демо-данные» для встреч `source=stub`

### Исправлено

- Meet и Телемост: 503 «не реализовано», без demo fixture в БД
- Трекеры: stub не пишет `connected: true` / `tracker_state=created` без API id
- Владелец встречи (`owner_user_id`); настройки PUT только для admin
- Миграция `tracker_type`: однократно (`PRAGMA user_version`), не затирает ClickUp
- Валидация settings и блок private webhook (SSRF)
- FTS: экранирование запроса, ошибка MATCH не глотается
- Таймауты LLM / OAuth / Asana / webhook / Whisper
- Email UNIQUE COLLATE NOCASE; rate limit логина; Secure cookie при HTTPS
- Asana: при падении API помечаются только успешные задачи
- После удаления default-проекта встреча снова создаёт проект
- `hasActiveJob` SQL вместо квадратичного обхода jobs
- Перезапуск бота: только admin и `{confirm:true}`
- `REVIEW_SKIPPED_NOTICE` в рисках резюме, не в `meeting.error`
- Настройки: «Сохранить» в строке проекта и разбор пустого JSON
- Существующая учётка после колонки `role` получает admin (иначе PUT настроек 403)
