# Asana: живой POST или очередь

**Контекст**

В макете есть «Отправить в Asana»; персонального токена может не быть. Сначала живую отправку отложили, затем вернули, если токен задан.

**Решение**

Без `ASANA_PAT` кнопка и автоотправка оставляют задачи «к отправке» внутри приложения. С токеном тот же жест делает живой HTTP POST в Asana.

**Почему**

Убрать кнопку ломает макет. Всегда ходить во внешний API без токена ломает демо-путь. Исходный D4 (только пометка, живой POST на следующий этап) не закрывает ручную и автоотправку, когда токен уже есть.

**Последствия**

Одна кнопка ведёт себя по-разному в зависимости от окружения. Автоотправка после готовой встречи зависит и от тумблера, и от наличия токена. Секрет живёт в переменной окружения: на экране настроек видно имя, не значение. Смена на OAuth Asana позже не отменяет уже накопленные «к отправке».
