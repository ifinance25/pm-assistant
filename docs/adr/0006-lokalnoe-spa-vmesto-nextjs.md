# Локальное SPA вместо Next.js

**Контекст**

Нужен интерфейс в браузере на этом Mac, без аккаунта хостинга и без экрана входа. Тот же язык, что у воркера.

**Решение**

Локальное одностраничное приложение (SPA): Vite + React + TypeScript. Рядом HTTP API на Node (Hono), слушает localhost, в dev проксируется с Vite.

**Почему**

Next.js тянет слой деплоя, серверные страницы и маршруты, которые на одном localhost не окупаются. Чистый статический HTML без React не тянет живые статусы встречи на нескольких экранах. Бэкенд на другом языке (Python, Go) удваивает сборку при одном авторе.

**Последствия**

Нет серверного рендера и нет «задеплоить на Vercel одной кнопкой». Выкладка в сеть позже потребует хостинг, HTTPS и пересмотр границы localhost. Смена UI-фреймворка это все экраны, не один модуль.
