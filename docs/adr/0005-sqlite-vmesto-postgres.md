# SQLite вместо Postgres

**Контекст**

Расшифровки, настройки и поиск по архиву должны жить на этой машине, без отдельного сервера баз данных.

**Решение**

Одна файловая SQLite на диске этого Mac. Веб и воркер делят этот файл; полнотекстовый поиск по архиву идёт в той же базе.

**Почему**

Postgres требует отдельный сервис, сеть и бэкапы, хотя пользователь один и машина одна. Хранение протоколов файлами (JSON, markdown) ломает поиск по архиву и общие настройки с воркером. Облачная база уносит тексты созвонов с компьютера.

**Последствия**

Нет одновременной записи с нескольких машин: второй клиент к тому же файлу это конфликт, не кластер. Пока диск недоступен, недоступны архив, настройки и очередь работ. Переезд на серверную СУБД позже это смена модели «один файл = всё состояние», не замена драйвера.
