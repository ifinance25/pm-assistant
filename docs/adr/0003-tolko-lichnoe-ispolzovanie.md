# Только личное использование

**Контекст**

В макете настроек есть «Команда» и «Биллинг». Продукт для одного человека на своей машине, не сервис на продажу.

**Решение**

Один пользователь, без экрана входа и ролей. Процесс слушает только localhost. Пункты «Команда» и «Биллинг» отсутствуют в навигации.

**Почему**

Мультипользователь тянет учётки, изоляцию данных и оплату, хотя продавать продукт не планируется. Оставить пункты как «скоро» создаёт ожидание облачного сервиса. Слушать все интерфейсы машины открыло бы соседям в локальной сети доступ без пароля.

**Последствия**

Второй человек позже потребует переписать границу доверия: сейчас любой процесс на этой машине может обратиться к API без пароля. Формального журнала согласий на запись нет: достаточно объявления в начале звонка, риск 152-ФЗ принят осознанно.
