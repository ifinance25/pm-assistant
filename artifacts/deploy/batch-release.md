# Пакетный релиз: копить мелочи, проверить пачку, выкатить скопом

Одна мелкая доработка не едет на прод сама. Она копится в пачку, пачка проходит тесты, на сервер уходит одним скопом. Перезапуск воркера только когда на проде никто не пишет звонок и не гоняет Whisper или саммари.

## Зачем так

Выкладка копирует код и затем перезапускает `pm-assistant-worker`. Перезапуск убивает живой `join` (бот выходит из Zoom) и рвёт идущий Whisper. Несколько мелких `sync.sh` подряд дают тот же риск несколько раз. Одна пачка: один риск, один чеклист, одна запись в `CHANGELOG.md`.

## Фаза 1. Копить (локально)

Каждая одиночная доработка:

1. Код и тесты в `app/`.
2. Одна строка в `CHANGELOG.md` между `<!-- unreleased:start -->` и `<!-- unreleased:end -->` (категория: Добавлено / Изменено / Исправлено).
3. Коротко в `log.md`, если это решение, не только правка.

На этом шаге **не** поднимать версию в `app/package.json` и **не** запускать `sync.sh`. Код живёт на Mac. Прод продолжает крутить прошлый релиз.

Пачка готова, когда в `unreleased` есть законченный набор (например три очереди воркера плюс соседние правки) и больше нет «ещё одну мелочь сразу на сервер».

## Фаза 2. Закрыть пачку и прогнать её

1. Поднять версию в `app/package.json`: PATCH (`0.2.2` → `0.2.3`) для поведения воркера и мелкого UI; MINOR только если меняется смысл продукта.
2. Из корня `app/`: `npm test`, затем `npm run build`.
3. Если менялись экран, вёрстка или клиентское состояние: пройти затронутый поток в браузере локально (`npm run dev`), не одним скриншотом.
4. `unreleased` в `CHANGELOG.md` это и есть состав пачки. `sync.sh` потом перенесёт его в секцию этой версии.

Критерий «пачка закрыта»: тесты зелёные, сборка проходит, в `unreleased` перечислено всё, что уедет.

## Фаза 3. Предполёт на проде

Перед копированием и перед перезапуском проверить, что воркер свободен. С Mac:

```bash
bash "Projects/PM Assistant/artifacts/deploy/preflight.sh"
```

Скрипт смотрит на EC2:

- задания `jobs` со статусом `running` (`join`, `transcribe`, `summarize`);
- встречи в `joining` / `waiting_room` / `recording` (бот в звонке);
- контейнеры Docker с меткой `pm-assistant.role=zoom-bot`.

Код выхода `0`: можно копировать и перезапускать. Код `2`: занято, печатает что именно крутится. Ждать конца звонка или конца Whisper, затем снова `preflight.sh`.

`pending` в очереди перезапуск переживает: после старта воркер их подхватит. Рвать нужно только `running` и живой вход в Zoom.

Аварийный обход (зависший бот, чинить прод важнее текущего задания): `FORCE_DEPLOY=1`. После такого обхода проверить, что встреча с wav ушла в `transcribe`, а не зависла в `joining`.

## Фаза 4. Выкладка скопом

1. Снова `preflight.sh` (код 0).
2. `bash "Projects/PM Assistant/artifacts/deploy/sync.sh"`: пишет секцию CHANGELOG из `unreleased`, копирует `app/` и `deploy/` на `/opt/pm-assistant/`. Идущий процесс Node ещё со старым кодом в памяти, пока его не перезапустили.
3. Снова `preflight.sh`. Если за время копирования кто-то начал созвон: **не** перезапускать, ждать.
4. На сервере (когда предполёт снова зелёный):

```bash
cd /opt/pm-assistant/app
export PATH=/opt/node-24/bin:$PATH
npm install
npm rebuild better-sqlite3
npm run build
sudo systemctl restart pm-assistant-api pm-assistant-worker
sudo bash /opt/pm-assistant/deploy/doctor.sh
```

`PATH` обязателен: без `/opt/node-24/bin` `npm rebuild` соберёт `better-sqlite3` под системный Node 22, API упадёт и вход перестанет работать.

`sync.sh` сам вызывает `preflight.sh`, если не задан `FORCE_DEPLOY=1`. Перезапуск юнитов руками: он и есть момент, когда старый воркер умирает.

## Фаза 5. Дым на проде

Через SSH-туннель (как в [README.md](README.md)):

- `GET /api/health`: `workerAlive: true`;
- вход, Главная, одна карточка встречи;
- если пачка трогала запись или очереди: убедиться, что `pending` задания снова в работе, а живой звонок не оборвался (его и не должно было быть в момент рестарта).

## Ритм одной фразой

Мелочь → строка в `unreleased` → копим. Пачка созрела → версия → тесты → предполёт → `sync.sh` → предполёт → restart → doctor → дым. Пока предполёт красный, прод не трогаем.
