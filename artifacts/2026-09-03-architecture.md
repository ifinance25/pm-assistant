**Связанные файлы:** продуктовая спецификация `artifacts/2026-09-03-pm-assistant-spec.md`, BUILD-спек `.autopilot/2026-09-03-pm-assistant-webapp--wip/spec.md`

## Что собираем

Локальное веб-приложение на этом Mac и отдельный процесс-воркер рядом. Один пользователь, без входа. Данные в SQLite, не в россыпи файлов.

## Стек

- Интерфейс: Vite + React + TypeScript
- HTTP API: Hono на Node, только `127.0.0.1`
- База: SQLite (`better-sqlite3`), полнотекстовый поиск FTS5
- Воркер: отдельный процесс Node, очередь заданий в той же базе
- Тесты: Vitest

Корень кода: `app/`.

## Потоки

1. Пользователь вставляет ссылку на Zoom / Google Meet / Яндекс.Телемост и нажимает «Отправить бота».
2. API создаёт встречу и задание в очереди.
3. Воркер: join (живой или заглушка) → объявление о записи → запись/фикстура → расшифровка → резюме и задачи.
4. Экраны показывают статусы, затем транскрипт, русское резюме и action items.
5. Кнопка Asana ставит задачам статус «к отправке» внутри приложения. Живая отправка отложена.

## Заглушки первой сдачи

- OAuth Zoom и Google Meet: только имена переменных в `.env.example`
- Телемост: интерфейс join есть; если гостевой вход нельзя стабильно сделать, помеченный симулятор
- STT: локальный движок если установлен, иначе фикстура
- LLM: предпочтительно `CLAUDE_CODE_OAUTH_TOKEN` (подписка, см. `artifacts/2026-09-03-claude-agent-sdk-subscription-on-server.md`); иначе ключ / фикстура. `ANTHROPIC_API_KEY` на сервере с подпиской не задавать
- Календарь: пункты и блоки на экране, без подключения
- Asana: без API
