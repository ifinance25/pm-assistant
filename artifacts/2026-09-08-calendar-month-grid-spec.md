# Спецификация: месячная сетка календаря (`/calendar`)

**Дата:** 2026-09-08
**Версия:** 1.1, утверждена и реализована 2026-09-08
**Источник дизайна:** `artifacts/designs/02-home-transcript-v2.pen`, узлы `gsvqb` (desktop «v2 Календарь») и `RfNN3` (mobile «Mobile v2 Календарь»), блок «Month Calendar»
**База:** фича раньше явно вынесена из объёма в `.autopilot/2026-09-06-mobile-responsive/spec.md` (пункт A01) как непропорциональная адаптации; пользователь 2026-09-08 подтвердил — оформляем и строим отдельно

**Правки пользователя при утверждении (2026-09-08):** клик по дню фильтрует список встреч ниже (в черновике 1.0 было «вне объёма»); стрелки месяца рабочие, не декоративные.

---

## 0. Зачем

Экран `/calendar` был только списком встреч на 7 дней вперёд (`CalendarView.tsx`). В макете `.pen` поверх него нарисована месячная сетка: шапка месяца со стрелками, строка дней недели, числа, сегодняшний день — закрашенный кружок. Пользователь одобрил вид в Pencil (десктопная и мобильная версии совпадают) и попросил перенести в реальный код с адаптацией под все размеры экрана и живой навигацией.

---

## 1. Что человек видит

Блок стоит **над** существующим содержимым `/calendar` (список событий), в ветке «календарь подключён» — баннеры «не подключён»/«истёк» не трогали.

- Заголовок месяца и года («Сентябрь 2026») по центру, стрелки ‹ › по бокам.
- Строка дней недели: Пн Вт Ср Чт Пт Сб Вс.
- Сетка чисел месяца по неделям, с пустыми ячейками до 1-го числа и после последнего.
- Сегодняшний день — число в кружке с акцентной заливкой, белый текст. На другом показанном месяце кружка нет.
- Стрелки переключают показанный месяц вперёд/назад — чисто клиентский пересчёт сетки, без обращения к серверу.
- Клик по дню (в любом показанном месяце) выбирает его: список ниже показывает только встречи этого дня. Повторный клик по тому же дню снимает выбор — список возвращается к обычным «7 дней вперёд».

## 2. Функциональные требования

| ID    | Требование                                                                                                                                | Приоритет |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------- |
| FR-01 | При открытии `/calendar` сетка показывает текущий месяц, с верным числом дней и верным сдвигом первой недели по дню недели 1-го числа       | P0        |
| FR-02 | Стрелки ‹ › переключают отображаемый месяц; пересчёт сетки — на клиенте, без запроса к серверу                                              | P0        |
| FR-03 | Сегодняшняя календарная дата (по времени браузера) отмечена кружком с акцентной заливкой; на любом другом показанном месяце отметки нет      | P0        |
| FR-04 | Блок встроен в `CalendarView` над списком, в ветке «подключён»; баннеры «не подключён»/«истёк» не переделывались                             | P0        |
| FR-05 | Сетка не ломается и не обрезается на телефоне (≤640px), планшете (641-1024px) и десктопе (>1024px) — общий порог проекта из `tokens.css`     | P0        |
| FR-06 | Дни недели и название месяца — русские, не зависят от локали браузера                                                                        | P0        |
| FR-07 | Клик по дню в сетке выбирает его; список ниже показывает только встречи этого дня вместо «7 дней вперёд»                                     | P0        |
| FR-08 | Повторный клик по уже выбранному дню снимает выбор — список возвращается к «7 дней вперёд»                                                   | P0        |
| FR-09 | `GET /api/calendar/events` принимает необязательные `from`/`to` (ISO); без них — старое поведение (7 дней от сейчас); с ними — окно под выбранный день | P0        |

**Вне объёма (осознанно, отдельные задачи при необходимости):**

- привязка встреч к ячейкам дня в самой сетке (точки/бейджи с числом событий);
- выбор дня отдельно от подсветки «сегодня» другим визуалом, кроме обводки;
- навигация по годам одной кнопкой;
- запоминание показанного месяца/выбранного дня между визитами или перезагрузкой;
- сетка в ветках «не подключён»/«истёк» (баннеры).

## 3. Реализация

- `app/src/web/pages/calendar/MonthGrid.tsx` — новый компонент: сетка месяца, своё состояние показанного месяца и выбранного дня, `date-fns` для расчёта дней/недель (единственная новая зависимость, только для дат — сама вёрстка и стили свои, без стороннего UI-виджета календаря).
- `CalendarView.tsx` — рендерит `MonthGrid` в ветке «подключён»; принимает `selectedDay`/`selectedDayEvents`/`onSelectDay` (все опциональные — старые тесты и вызовы не сломаны).
- `CalendarPage.tsx` — хранит `selectedDay`, при выборе дня делает отдельный запрос `/api/calendar/events?from=...&to=...` (границы суток дня, `date-fns` `startOfDay`/`endOfDay`) и передаёт результат в `CalendarView`.
- `app/src/adapters/calendar/google.ts` (`listUpcomingEvents`) и `app/src/server/routes/calendar.ts` — необязательный диапазон `timeMin`/`timeMax` вместо жёстко зашитых 7 дней; без параметров поведение не изменилось.
- Стили — `calendar.css`, `.month-grid*`, по паттерну проекта (`var(--card)`, `var(--radius-card)`, `var(--accent)`, `var(--surface-tertiary)`). День — кружок фиксированного размера (36px, 32px на ≤640px), а не тянется по ширине колонки: при первой реализации кружок растягивался до ~200px на десктопе (`aspect-ratio` без верхнего предела), поймано визуальной проверкой и исправлено.
- Новых типов в `shared/types.ts` и новых таблиц в БД не потребовалось.
