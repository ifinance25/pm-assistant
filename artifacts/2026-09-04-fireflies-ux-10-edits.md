## Короткий вывод

Fireflies продаёт «память компании»: бот Fred, блокнот после звонка, поиск по фразе, AskFred, каналы и 200+ навыков. Для личного PM Assistant это слишком широкий и командный продукт. Брать нужно не фиолетовый бренд и не лендинг, а три рабочих паттерна: **захват как главное действие**, **блокнот с одной доминирующей зоной**, **прыжок из поиска и задачи к моменту записи**.

Текущие макеты Style B уже теплее и «свои», чем типичный SaaS. Слабое место не палитра, а иерархия задач. На Главной поле ссылки (реальный способ отправить бота) спрятано справа, а героем выглядит ближайшая встреча, хотя календарь в этой версии выключен. На итогах три равные колонки спорят за внимание, нет плеера, нет вопроса к этой встрече, поиск не показывает совпадения.

Новый прототип: только Главная и экран расшифровки, канон Style B сохранён.

## Дизайн-система Fireflies (подробно)

Источник: маркетинг [fireflies.ai](https://fireflies.ai/), страницы Notetaker / Features / Conversation Intelligence / Live Assist, скрины блокнота и AskFred с тех же страниц. Живой `app.fireflies.ai` за логином не разбирался: продуктовый хром восстановлен по маркетинговым кадрам и справке.

### Цвет

- **Бренд:** насыщенный фиолетовый как единственный primary CTA (Share, Get Started, кнопка отправки в AskFred). Это Committed-стратегия на маркетинге и точечный акцент в приложении.
- **Продукт:** белая сцена, светло-серый холст, тёмно-серый текст. Семантика отдельно: бирюза `REC`, мятный/teal для выполненной задачи, розовые и оранжевые бирки имён, голубая подсветка хайлайтов в заметках.
- **Маркетинг:** тёмно-фиолетовые подложки, «звёздные» градиенты, логотипы клиентов. Это Persuade, в Operate-приложение его тащить нельзя.



### Шрифт

- Один нейтральный гротеск (близко к Inter / системному UI). Имена спикеров жирные, тело серое, таймкоды меньше и цветные (синяя ссылка).
- Иерархия спокойная: 1.125-1.2 между ступенями. Display-серifs нет. Для Operate это правильный пол.



### Отступы, радиус, плотность

- Воздух: большие скругления карточек (16-24), пилюли для статусов, поиск на полную ширину колонки.
- Плотность **средняя**: транскрипт читаемый, не таблица. Маркетинг ещё воздушнее, продукт плотнее.
- Сайдбар узкий, контент на белых панелях.



### Высота (elevation) и движение

- Карточка AskFred: лёгкая тень со смещением, поле ввода «плывёт» над тредом.
- Шапка блокнота плоская, белая, без стекла.
- Движение на маркетинге декоративное; в продукте ожидаемы 150-250 мс на состояние, без постановки при загрузке.



### Фото и иллюстрации

- Маркетинг: фото людей, 3D-кнопка Dock, скрины продукта в телефонах и ноутбуках, логотипы AssemblyAI / Emaar.
- Продукт: аватары (фото или инициал в цветном скруглении), иконки-контуры у секций Overview / Notes / Action items. Маскота-светлячка на экранах работы почти нет, он живёт в маркетинге и иконке AskFred.



### Иерархия CTA

- Маркетинг: Get Started (логин) + Request Demo. Фиолетовая заливка vs контур.
- Блокнот: Share в шапке, Soundbite вторичен, плюс для участников. Внутри транскрипта primary нет: читать и кликать таймкод.
- AskFred: фиолетовая стрелка отправки, плейсхолдер «Ask anything...».



### Что в системе категории, что реально хорошо


| Приём                     | Категория (есть у всех) | Сильная сторона Fireflies                                                            |
| ------------------------- | ----------------------- | ------------------------------------------------------------------------------------ |
| Бот на встрече            | Да                      | Имя Fred + несколько каналов захвата (календарь, ссылка, десктоп, расширение, файл)  |
| Саммари + задачи          | Да                      | Вкладки блокнота: Overview / Bullet / Action Items / Custom, а не три равные колонки |
| Поиск                     | Да                      | Прыжок к предложению и таймкоду, не «поиск по сервису» без модели выдачи             |
| Спросить ИИ               | Да в 2025-26            | AskFred **в контексте этой встречи**, модель видна (GPT-4o)                          |
| Аналитика речи            | Корпоративный CI        | Talk-time, sentiment, topic trackers: для личного PM лишнее                          |
| Каналы, Soundbites, Share | Команда                 | Для личного сервиса шум                                                              |
| 200+ AI Skills            | Магазин                 | Не наш масштаб                                                                       |
| Live Assist               | Новый слой              | Подсказки во время звонка: после базового «ссылка → текст → задачи»                  |

## Компоновка и UX-паттерны



### Маркетинг (Persuade)

Верх: Product / Solutions / Integration / Resources / Enterprise / Pricing, Login, Get Started. Герой: «The #1 AI Assistant For Your Meetings», транскрибируй / суммируй / ищи / анализируй. Доказательства: G2 4.8, GDPR/SOC2, лента логотипов. Дальше: точность 95%, 100+ языков, спикеры, автоязык; блокнот; захват везде; поиск и AskFred; Live Assist; CI; Tasks/Contacts/Feed; Skills; интеграции; security.

Это витрина платформы. У PM Assistant витрины нет и не будет (личное использование).

### Продуктовый хром (по кадрам блокнота)

- Слева гамбургер, в шапке **хлебные крошки** `# Sales / Kickoff Call`, бейдж `REC`.
- Справа: Soundbite, фиолетовый Share, плюс, аватар.
- Транскрипт: заголовок колонки, поиск, аватар + имя + шеврон (переназначить спикера) + **синий кликабельный таймкод** + абзац + иконка закладки.
- Саммари-карточка: иконка календаря, Overview, Notes с цветной подсветкой «Use Case / Requirement», Action items с чекбоксом, биркой имени и аватаром.
- AskFred: отдельное окно поверх, не третья равная колонка.



### Потоки

1. **Захват:** пригласить `fred@fireflies.ai` / автоджойн по календарю / расширение Meet / десктоп / загрузка файла.
2. **Разбор:** открыть встречу → вкладка блокнота → слушать с таймкода.
3. **Спросить:** AskFred по этой встрече или по архиву.
4. **Задачи:** извлечь и отправить в Asana / CRM.
5. **Команда:** каналы, шаринг, правила автоджойна. Для нас шаги 4-5 сужаются до «пометить к отправке в Asana».

## Разрыв с текущими прототипами

Канон `00-all-screens.pen` / `01-home.pen`, сверка с `HomeView.tsx` и `MeetingView.tsx`.

**Главная.** Живой код уже честнее макета: герой, если есть живая встреча, иначе пусто; ручной запуск справа; хранилище считает встречи и байты. Макет всё равно ставит карточку «следующая встреча» и тёмную плашку ссылки как придаток. Поиск в шапке без модели выдачи. «Записать / В эфир» на соседних строках расходятся с глаголом продукта «Отправить бота». Квота «9.2 из 10 ГБ» выглядит как облачный тариф, в коде потолок другой и подпись уже «на этом компьютере».

**Итоги / расшифровка.** Три равные колонки. В шапке «+ Новое» без смысла. Поиск по итогам дублирует поиск по транскрипту. Таймкоды в коде кликабельны, в макете это слабо читается как плеер. Слайды и голосовой отпечаток в коде как заглушки: в v2 не раздуваем. Asana-подсказка «без токена только пометка» в коде есть, в макете легко пропадает за статусами «СРОЧНО / В РАБОТЕ», которых в данных нет.

## 10 правок

Отсортированы по убыванию значимости и эффекта. Правка = изменение UI/UX прототипа, не стратегия продукта.

### 1. Поле ссылки: доминирующая зона Главной

- **Зачем:** время до ценности. Единственный рабочий захват сейчас: `POST /api/meetings` со ссылкой. Если это справа в тёмной карточке, человек ищет календарь, которого нет.
- **У Fireflies:** захват (Fred / календарь / ссылка) не прячут за «следующим эвентом».
- **Что менять:** крупный блок «Отправить бота на звонок»: поле, распознанная платформа, кнопка «Отправить бота». Ближайшие звонки ниже.



### 2. Одна доминирующая колонка и вкладки блокнота

- **Зачем:** сканируемость. Три равные колонки: 8+ объектов решения сразу, высокая посторонняя нагрузка.
- **У Fireflies:** вкладки Overview / Transcript / Action Items, шапка встречи отделена.
- **Что менять:** транскрипт ~60% ширины. Справа вкладки «Обзор» и «Задачи», не третья равная колонка.



### 3. Конвейер статуса как лента, не открытка «бот свободен»

- **Зачем:** доверие в ожидании. Статусы уже есть: очередь → вход → запись → расшифровка → резюме → готово / ошибка.
- **У Fireflies:** бейдж REC, обработка после звонка (их слабость: 10-15 мин). Мы можем показать шаг честно.
- **Что менять:** на Главной полоса живой встречи со степпером. На расшифровке бейдж статуса в шапке, без декоративной «свободы бота» вместо пайплайна.



### 4. Поиск с прыжком к предложению

- **Зачем:** работа «вспомнить, что сказали». Пустой поиск в шапке не закрывает задачу.
- **У Fireflies:** Meeting Search до предложения и таймкода.
- **Что менять:** Главная: «Найти встречу или фразу». Экран расшифровки: запрос, «N совпадений», prev/next, подсветка в строке. Глобальный дубль «Поиск по итогам» убрать.



### 5. Плеер и синхрон таймкодов

- **Зачем:** проверка спорной фразы. Аудио уже пишется, в макете его нет: таймкод ощущается декорацией.
- **У Fireflies:** синий кликабельный таймкод = позиция в записи.
- **Что менять:** полоса воспроизведения на всю ширину. Строка транскрипта с playhead. Таймкод терракотовый, как ссылка.



### 6. Спросить по этой встрече

- **Зачем:** ценность языковой модели там, где уже есть резюме. Без чата человек перечитывает сырой текст.
- **У Fireflies:** AskFred в контексте встречи.
- **Что менять:** поле внизу правой колонки «Спросить по этой встрече», подсказки «Какие решения?» / «Что в Asana?». Без имени Fred и без фиолетового.



### 7. Фильтры спикеров и типа реплик

- **Зачем:** длинный транскрипт. Сейчас только строка поиска.
- **У Fireflies:** AI Filters (вопросы, задачи, метрики).
- **Что менять:** чипы Все / Илья / Ника / Сергей / Вопросы / Решения / Задачи. Не полноценный CI.



### 8. Задача как якорь на момент плюс честная Asana

- **Зачем:** довести разбор до действия. В коде уже есть `timecodeMs`, якорь на сегмент и `asanaState`.
- **У Fireflies:** задача с именем, чекбоксом, автоотправка в Asana.
- **Что менять:** чип таймкода на задаче, подпись Asana «не отправлена / к отправке / отправлена». Кнопка «Отправить N задач в Asana» только если есть `none`. Подсказка про отсутствие токена. Убрать выдуманные «СРОЧНО / В РАБОТЕ».



### 9. Последние расшифровки как сущности

- **Зачем:** узнать исход, не только имя файла. Сейчас иконка + дата + статус.
- **У Fireflies:** список встреч: название, длительность, участники, кусок обзора.
- **Что менять:** платформа · длительность · дата, бейдж Готово/Резюме/Ошибка, одна строка результата.



### 10. Честный хром: локальность, календарь, без «+ Новое»

- **Зачем:** соответствие продукта. Лишний CTA и облачная квота ломают доверие.
- **У Fireflies:** Share и квоты минут уместны команде. Нам нет.
- **Что менять:** сайдбар: «Календарь выключён». Хранилище: «N встреч · M МБ на этом компьютере». На расшифровке крошка «Главная», без «+ Новое».

## Что сознательно не копировали

- Фиолетовый как идентичность, логотип светлячка, имя Fred, энергия лендинга Get Started.
- Share, Soundbites, каналы, Contacts, Skills Store, Live Assist во время звонка.
- Talk-time / sentiment / topic trackers (личный сервис, не CI для команды).
- Письмо за час и opt-out всем гостям: в Pulse согласие = голосовое объявление организатора.
- GraphQL API и биллинг как экраны.
- Английский UI и «95% accuracy» как претензия: качество русского у Fireflies как раз слабое, наш упор другой.

## Дополнение 2026-09-04: проекты, Jira Epic, остальные экраны

Продуктовое решение прототипа: каждая запись принадлежит проекту. У проекта две настройки: ссылка на проект Jira и ссылка на Epic. Счётчик расшифровок в разрезе проектов: главный скан Главной после блока «Отправить бота». Полоса «помечены к отправке в Asana» с Главной снята: задача живёт на встрече. Живое приложение и спека пока Asana, пока не попросили внедрять.

### Правки по Архиву, Календарю, Настройкам (по убыванию)

Канон смотрели в `00-all-screens.pen` (ячейки Календарь, Расшифровки, Настройки). В v2 те же экраны пересобраны под проекты и Jira.

1. **Архив: фильтр по проекту важнее фильтра по Zoom/Meet.** В каноне чипы источника и периода. Человек ищет «что было по Своим», не «все Zoom за месяц». В `v2 Архив`: чипы проектов, затем статус; карточка несёт имя проекта.
2. **Архив: выбранная встреча показывает Epic, не цитату «в Asana».** Правая колонка: проект, `Epic ROAD-100`, счётчики, «Открыть встречу». Задачи по-прежнему на экране расшифровки.
3. **Календарь: честный выключенный режим как главный текст.** Канон уже говорил, что Google/Apple в Настройках. v2 усиливает: нет сетки недели, баннер «живой календарь не подключается», список только из базы, с проектом и ссылкой.
4. **Календарь: CTA по состоянию встречи.** Уже идёт или готово: «Открыть». Ещё не записано: «Отправить бота». Не выдумывать автоджойн.
5. **Настройки: блок проектов с Jira и Epic вместо автоотправки в Asana.** Канон ставил «проект: PM Assistant / встречи» и тумблер Asana. v2: таблица из четырёх проектов, URL проекта Jira + ключ Epic. Это полный список настроек; на Главной тот же смысл, но одна карточка раскрыта.
6. **Настройки: календарь и звонки остаются «по ссылке».** Google/Outlook не подключены, локальный список активен. Подпись «сейчас»: локальный звук, задачи уходят из встречи в Epic.
7. **Архив и календарь не получают очередь задач.** Ни общего Jira-инбокса, ни Asana-ленты. Иначе Главную только что почистили зря.
8. **Сайдбар на этих экранах тот же, что на Главной.** Сворачивание не отдельная «страница настроек». Пункт «Проекты» на Главной ведёт к блоку счётчиков; на Настройках тот же список с полями.

## Дополнение 2026-09-05 (вечер): Google OAuth на входе

На `v2 Вход` первый способ входа: кнопка «Войти через Google» (белая, обводка, цветная метка G). Ниже разделитель «или», затем почта или локальный аккаунт, пароль и «Войти». Для живой реализации (пока только прототип): OAuth callback, сессия после редиректа. Переменные `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` уже в `.env.example` для Meet; можно переиспользовать тот же OAuth-приложение Google или завести отдельное для auth, если нужны разные redirect URI.
